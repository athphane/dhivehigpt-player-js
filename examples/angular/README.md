# Angular example

Unlike the other `examples/*` directories, this isn't a runnable project — Angular has no lightweight way to run a single component outside a full Angular CLI workspace. It's a copy-in recipe instead:

- `dhivehigpt-player.component.ts` — a small standalone Angular component wrapping `AudioPlayer`. Copy this file into your own Angular project.
- `article.component.html` — how to use it in a template once copied in.

See [docs/modules/angular.md](../../docs/modules/angular.md) for the full explanation.
